Issues, questions, and pull requests are welcome. [CONTRIBUTING.md](https://github.com/meocord/meocord/blob/8db9ae608492f31201c30388e4a1aa3cd30b98a1/CONTRIBUTING.md) covers getting set up, what each check exists to catch, and how releases work — a change that reaches the published package carries a [changeset](https://github.com/changesets/changesets), and merging the release pull request is what publishes it.

Participation is governed by the [Code of Conduct](https://github.com/meocord/meocord/blob/8db9ae608492f31201c30388e4a1aa3cd30b98a1/CODE_OF_CONDUCT.md). For vulnerabilities, follow [SECURITY.md](https://github.com/meocord/meocord/blob/8db9ae608492f31201c30388e4a1aa3cd30b98a1/SECURITY.md) rather than opening an issue.
